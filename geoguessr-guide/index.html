02 · ЯЗЫКИ

Уникальные письменности + похожая латиница в одном месте

Японский, корейский и китайский: сравни глазами

🇯🇵 Японский — смесь знаков

東京へ行く

Сложные иероглифы стоят рядом с простыми знаками. Здесь へ и く — японская азбука.

の り ひ あ · カ タ ナ

Хирагана бывает округлой, катакана — угловатой. Обе состоят из отдельных знаков: округлость сама по себе страну не определяет.

🇰🇷 Корейский — блоки из букв

한 국 역

Внутри каждого блока несколько простых букв: 한 = ㅎ + ㅏ + ㄴ. Они стоят рядом и друг над другом.

ㅇ ㅁ ㄴ ㅏ ㅗ

Ищи повторяющиеся кружки ㅇ, прямые углы и палочки с коротким ответвлением. Не в каждом блоке есть круг; один круг без остальных признаков ничего не решает.

🇨🇳 Китайский — иероглифы

中 山 路

Каждый знак — отдельный иероглиф; нет японской азбуки の / り / カ и корейских букв, собранных в слоговые блоки.

车站 · 車站

Пример: «станция» в упрощённом и традиционном письме. Знаки бывают и простыми (山), и сложными (灣): число штрихов само по себе не решает.

Порядок проверки: блоки вроде 한 / 역 → корейский; знаки の / り / カ среди иероглифов → японский. Только иероглифы — пока неоднозначно: японская вывеска 東京 тоже может быть без азбуки. Найди ещё текст и проверь движение: Япония и Гонконг — слева, Тайвань и материковый Китай — справа. Китайское письмо встречается также в Сингапуре и других странах.
