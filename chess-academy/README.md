# Личная шахматная академия

Локальное русскоязычное приложение: Python 3.12+, FastAPI, python-chess, Stockfish 17.1, SQLite и браузерный интерфейс без CDN. Не требует регистрации, платных сервисов и внешних моделей. Есть два способа запуска: браузерная версия на GitHub Pages и исходная версия с Python/SQLite.

## Открыть без установки — GitHub Pages

**https://ssanekmix.github.io/chess-academy/**

Откройте ссылку и нажмите «Продолжить обучение». Python, распаковка и локальный сервер не нужны. Stockfish 17.1 Lite WebAssembly (~7 МБ) работает в отдельном потоке браузера; вычисления и личные данные остаются на вашем устройстве. Поддерживается современный Chrome, Edge или Firefox с WebAssembly и IndexedDB. Учебные материалы, движок и код поставляются с сайтом, без CDN.

Доступны доска, курсы, ECO, свои ветки, локальный анализ, PGN, упражнения, заметки, повторения и прогресс. Приложение сохраняется через Service Worker: дождитесь надписи «Приложение сохранено для работы без интернета», затем можно открывать его автономно. Если браузер поддерживает установку PWA, появится кнопка «Установить как приложение»; также можно создать ярлык штатным меню браузера.

Прогресс браузерной версии хранится в **IndexedDB этого браузера на этом устройстве**. Он не публикуется в GitHub и не синхронизируется между устройствами. Перед очисткой данных браузера или сменой устройства скачайте JSON в разделе «Прогресс». Перед восстановлением автоматически сохраняется отдельная копия прежних данных; её можно скачать там же. Записи из нескольких вкладок сериализуются блокировкой на время транзакции; вкладки получают уведомления об изменениях. Обновление схемы IndexedDB сохраняет существующие данные. JSON браузерной версии и резервная копия Python/SQLite имеют разные форматы.

Chess.com и Lichess запрашиваются прямо из браузера. Их доступность зависит от сервиса, CORS и сети; при отказе доступны локальные данные и ручной PGN-импорт. Облегчённая WASM-сборка и нативный Stockfish могут выдавать разные ограниченные оценки; они не заявляются идентичными. Проверка HTTP 401 Explorer остаётся отдельной задачей.

Для разработки статической версии из корня репозитория:

```sh
python -m http.server 8800 --bind 127.0.0.1
```

Открывайте путь `/chess-academy/` этого сервера. Проверка **без FastAPI и без серверного API**, с настоящим WASM-движком, автономным запуском и IndexedDB:

```sh
python chess-academy/tests/web_smoke.py
```

Нужны Playwright и Chromium (см. ниже). Тест сам запускает временный статический HTTP-сервер. При выпуске обновлений меняйте `VERSION` в `sw.js`; иначе уже установленные копии могут продолжить использовать прежний кеш.

## Обновление: тёмный учебный интерфейс

Веб-версия получила тёмный интерфейс с большой доской, векторными фигурами Cburnett, перетаскиванием, диалогом превращения, шкалой реальной оценки и вкладками «Разбор / Ходы / Движок». Стиль привычен пользователям шахматных сайтов; бренд и защищённые материалы Chess.com не копируются.

### Ошибка → опровержение → новая попытка

Во всех тренировочных режимах ход сначала проверяется. При существенной ошибке тренер показывает ход и лучший найденный ответ соперника, объясняет конкретную проблему и **возвращает исходную позицию**. Ошибочный ход не записывается в историю варианта. Можно повторно воспроизвести ответ, показать сильный ход стрелкой и попробовать снова. Право на повторение не блокируется расписанием.

В пограничных случаях повторный расчёт выполняется из той же исходной позиции с фиксированным ходом-кандидатом. Подготовленные теоретические ходы и близкие игровые альтернативы не запрещаются из-за небольшого расхождения неглубоких оценок. Свободное исследование намеренно позволяет исследовать любой легальный ход; это отдельный режим для проверки идей.

В разобранной партии кнопка «Исправить ошибку» открывает исходную позицию как упражнение. Все оценки ограничены мощностью и временем поиска; найденная PV подтверждает легальность и расчёт конкретной линии, но не доказывает вынужденность каждого ответа.

### Бесплатные задачи Lichess

В разделе «Задачи» используется официальный публичный `GET https://lichess.org/api/puzzle/next`. Новая задача запрашивается по действию пользователя, с выбором темы и сложности. **Дневного лимита или платной подписки в академии нет.** Приложение соблюдает паузы и HTTP 429 источника; частота внешнего API не контролируется академией. Эндпоинт не используется для массового скачивания.

Для автономной работы включён отдельный проверенный на легальность набор **4 096 задач** из открытой базы Lichess CC0. Первичная подготовка прочитала только 327 680 байт сжатого потока и остановилась, не скачивая весь архив. Наборы небольшие и проверяются по SHA-256. Офлайн-выборка конечна: после её исчерпания доступны повторения, а новые онлайн-задачи требуют сети. Это не обещание бесконечного числа уникальных позиций без интернета.

Многоходовая задача продолжается после первого правильного хода: соперник отвечает, и нужно найти следующий ход. Решение засчитывается и попадает в повторения после окончания всей последовательности; практически равноценная альтернатива может быть принята по движку с соответствующим объяснением. Ходы официальной линии помечаются источником; все оценки не выдаются за независимое глубокое доказательство.

### 10 углублённых дебютных программ

Итальянская, испанская, шотландская, сицилианская, французская, Каро-Канн, ферзевый гамбит, славянская, староиндийская и защита Нимцовича: **1 765 именованных веток** из открытой ECO-базы плюс авторские русские планы за оба цвета. Остальные шесть базовых программ сохранены.

У каждой программы есть главы с поиском, планы белых/чёрных, описание структуры, типичные ошибки и переход в миттельшпиль. Записанные ветки доходят до 10–18 полных ходов в зависимости от дебюта. **На этом анализ не заканчивается:** можно продолжать любую легальную ветку, получать MultiPV и объяснение каждого хода до завершения партии. Неизвестная движковая ветка не называется подготовленной теорией. Именованный ECO-вариант также не обязательно является рекомендацией: среди них есть редкие гамбиты и ошибки, которые нужно проверять.

Разбор хода содержит восемь разделов: идея, ответ соперника, атаки/защита, центр/развитие/король, пешечная структура, проверенные угрозы, конкретная альтернатива и следующий план. Текст строится из фактов позиции, авторской памятки и действительного расчёта. Полнота перечня ходов в шахматах или решение всех дебютов не заявляются.

### Подключение публичного профиля

Откройте «Мой профиль», введите ник Chess.com и нажмите «Подключить профиль». Загружаются реальные опубликованные рейтинги, затем можно импортировать завершённые партии из архивов. Пароль и токен не требуются; подключение по нику не подтверждает владение аккаунтом. Рейтинги и профиль сохраняются на вашем устройстве.

Для Lichess реализованы публичный профиль и NDJSON-экспорт завершённых стандартных партий. Партии с любой другой платформы можно бесплатно импортировать через PGN. Приложение не подключается к текущей игре и не выполняет ходы на внешнем сайте. Повторные импорты не создают копии. Анализ и упражнения выполняются локально, без оплаты за партии.

**Проверки новых сценариев:** `python chess-academy/tests/web_training.py` из корня репозитория. Сценарий использует настоящую WASM-сборку и явные API-фикстуры; проверяет 10 деревьев, корректные альтернативы, возврат ошибочных ходов, перетаскивание, полную многоходовую задачу, профили, finished-only импорт и офлайн-набор. Живые публичные API отдельно проверялись через HTTPS: задача Lichess, профиль Chess.com и разбор завершённой партии Lichess на 77 полуходов с созданием семи упражнений.

## Запуск на Windows

1. Установите **64-битный Python 3.12 или новее** с https://www.python.org/downloads/windows/; включите `Add Python to PATH`.
2. Скачайте репозиторий, распакуйте его и откройте каталог `chess-academy`.
3. Дважды нажмите **start.bat**. Либо выполните в этом каталоге `py -3 run.py`.

Первый запуск создаст `.venv`, установит закреплённые зависимости из `requirements.lock`, скачает официальную универсальную Windows x86-64 сборку Stockfish (~63 МБ) и небольшую открытую базу дебютов. SHA-256 архива проверяется перед распаковкой. Браузер открывается автоматически после готовности сервера. Остановка — Ctrl+C в окне запуска. Не удаляйте каталог `data`: в нём ваши партии, заметки и прогресс.

При нескольких Python команда `py -3` должна выбирать версию не ниже 3.12; иначе запустите `py -3.12 run.py` вручную. Запуск именно на Windows пока не проверен на реальной Windows-машине; Linux и Chromium проверены. Для ARM Windows установите подходящую официальную сборку Stockfish самостоятельно и задайте `STOCKFISH_PATH`.

После успешной первой установки возможен запуск без интернета:

```bat
py -3 run.py --offline
```

Если движок установлен отдельно, перед запуском задайте путь:

```bat
set "STOCKFISH_PATH=C:\Stockfish\stockfish.exe"
py -3 run.py
```

## Linux / облачная среда

Из каталога `chess-academy`:

```sh
python3 run.py --no-browser
```

Автоматическая сборка Linux рассчитана на x86-64 с AVX2. Для других CPU/систем используйте официальную совместимую сборку и `STOCKFISH_PATH`; автоматическая загрузка для macOS/ARM пока не реализована. Python сам проверяет платформу до скачивания.

Ручная установка и запуск:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python setup_local.py
.venv/bin/python -m uvicorn academy.main:app --host 127.0.0.1 --port 8765
```

Сервер слушает только loopback, порт **8765**. Этот порт также зафиксирован для проверки Origin. При занятом порте проверьте уже запущенный экземпляр. Логи Uvicorn и ошибки фоновых задач выводятся в терминал; при необходимости перенаправьте их в собственный файл. Локальный адрес выводит программа запуска; облачный onboarding не предоставляет веб-превью.

## Что можно делать

- Выбрать один из **16 авторских дебютных курсов**, каждый с тремя ветками; играть за белых, чёрных или обе стороны. Начинайте с первых 5–6 ходов и объяснений, а не с заучивания длинной последовательности.
- Найти другой дебют среди **3 865 названий ECO** из `lichess-org/chess-openings` (закреплённая версия CC0). Дополнительная база сохраняет международные названия, авторские курсы — русские.
- Добавлять собственные PGN-ветки в личный репертуар без ограничения количества. Одинаковое название и цвет объединяют ветки. PGN репертуара может заканчиваться `*`; импорт **партий**, напротив, принимает только завершённые записи с результатом.
- Делать любой легальный ход, включая уход из подготовленного дерева, рокировку, взятие на проходе и превращение с выбором фигуры. Список всех легальных ходов доступен отдельно. Поддерживаются мат, пат, недостаточный материал, правило 50 ходов и повторения. При наличии права заявить ничью приложение помечает её как результат; отдельной кнопки заявления пока нет.
- Возвращаться по истории, переворачивать доску, видеть стрелку последнего/предложенного хода и поля, атакуемые соперником, сохранять FEN и заметки.
- Запрашивать MultiPV, глубину и лимит времени; смотреть проверенные движком продолжения, воспроизводить их шагами и сравнивать ход кнопкой «Почему?». «Что будет, если…» включает свободное исследование альтернативы.
- Тренировать память выбранной ветки, угадывать сильный ход, играть с ответами соперника. В режиме случайного соперника сначала используются ветки выбранного дебюта; вне них — MultiPV. Вероятности выбирают ранги, а не гарантируют качество/ошибку.
- Находить ошибку и лучший ответ на неточность из разобранных партий. Текстовое объяснение — самооценка, программа не выдаёт её за автоматическую проверку понимания.
- Импортировать законченные стандартные партии из PGN или месячного публичного архива Chess.com. Стандартный ник — `Sanekmix`, его можно изменить. Никакого взаимодействия с текущей партией, автоматизации сайта и авторизации Chess.com нет.
- Разбирать партию фоновой задачей, видеть график оценки белых, ошибочные решения, лучшие альтернативы и конкретные ответы. После **полного** анализа ошибки выбранного пользователя превращаются в упражнения. Если ник не совпадает ни с одним игроком, упражнения создаются для обоих цветов.
- Решать упражнения по своим ошибкам и **10 подготовленным задачам**, читать короткие материалы по тактике, стратегии и эндшпилю; создавать новые упражнения из любой незавершённой позиции с решением Stockfish.
- Повторять упражнения по расписанию: ошибка — 10 минут, успехи — 1 день, 6 дней, далее интервал увеличивается с учётом сложности. Подсказка снижает оценку ответа. Равноценные движковые альтернативы принимаются.
- Видеть результаты тренировок, этап программы, дебютные результаты по цвету, рейтинги по контролям при наличии метаданных Chess.com и остатки часов при наличии `%clk` в PGN. Малые выборки помечаются; выводы о причинах цейтнота из одного остатка времени не делаются.

## Как устроен анализ

Одна ограниченная очередь на 12 активных/ожидающих задач, один поток Stockfish и 64 МБ Hash. Остановка проверяется перед и после UCI-запроса: задержка может достигать заданного лимита одного запроса (до 5 секунд). Очередь не восстанавливается после перезапуска; сохранённые завершённые результаты остаются.

Оценки хранятся со стороны белых. Классификация воспроизводима для фиксированных входных оценок и сочетает потерю ожидаемого результата по WDL-модели Stockfish, изменение centipawn и контекст найденного мата. Это **не** Chess.com Accuracy. Один только спад с +12 до +7 не становится грубым зевком при одинаково выигранном WDL. Ограниченный по времени движок может выдавать разные оценки между запусками; спорные решения требуют углубления.

Идентичность позиции: первые четыре поля FEN, включая сторону, рокировки и только **легальное** взятие на проходе. В анализ-кеш также входят полные счётчики, история ходов, движок и параметры, чтобы не путать право на ничью и обычную позицию. Нормализованные таблицы `positions`, `moves`, `variations`, `variation_moves` объединяют транспозиции. Дерево не разворачивается целиком: сервер отдаёт текущую позицию и ограниченный список её веток.

Объяснения основаны на авторских заметках, проверяемой геометрии доски и реальном UCI-продолжении. Наличие атаки не выдаётся за выгодное взятие; PV не называется вынужденной, если это не доказано. Для неподготовленных позиций явно указано отсутствие подробного методического разбора. Автоматическая генерация всех восьми компонентов глубокого объяснения, распознавание всех тактических мотивов и полноценная многолетняя программа пока **не завершены**; см. TASKS.md.

## Интернет и источники

Обязателен только при первой установке: `pypi.org`, `files.pythonhosted.org`, `github.com`, `release-assets.githubusercontent.com`, `raw.githubusercontent.com`. Никакие многогигабайтные базы не скачиваются.

Для необязательных онлайн-функций:

- `https://explorer.lichess.org/masters` — партии мастеров.
- `https://explorer.lichess.org/lichess` — любительские выборки: группы рейтинга `0,1000` (до 1200) и `2000,2200,2500`. Рейтинг Lichess не равен Chess.com. API возвращает `white`, `draws`, `black`; частоты и результаты вычисляются из реальных чисел, оценки не выдумываются.
- `https://api.chess.com/pub/player/{username}/games/archives` и `/games/{YYYY}/{MM}` — архивы завершённых партий. Не используются ссылки на произвольные URL из пользовательского ввода.

Запросы обоих сервисов выполняются последовательно, с паузой не менее 1 секунды. При 429 действует `Retry-After` (не меньше 60 секунд); автоматического бесконечного повтора нет. Кеш хранится в SQLite; при недоступности сервиса старые данные возвращаются с пометкой. Без кеша показывается понятная ошибка, локальные функции продолжают работать. Сравнить выборки можно тремя кнопками Explorer; это наблюдаемая частота, не доказательство правильности.

**В текущей облачной среде** первоначально сетевой прокси блокировал оба сервиса. После добавления доменов повторная проверка подтвердила живой доступ к архивам и месячному JSON Chess.com. Explorer на обоих хостах возвращает `401 Authorization Required`; причина отказа публичного запроса пока не установлена. Его контрактные проверки и отображение работают, успешный живой запрос ещё не подтверждён. Токен вслепую не запрашивается. Изменения сетевых настроек сохранены в черновике; публикация среды выполняется отдельно.

## Данные и резервные копии

`data/academy.sqlite3` — пользовательская база; `data/openings/` — небольшие исходные TSV и лицензия. Эти файлы, `.venv`, инструменты и артефакты тестов исключены из Git. Путь данных можно изменить через `ACADEMY_DATA`; путь движка — через `STOCKFISH_PATH`. Переменные не обязательны.

В разделе «Прогресс» доступны JSON-экспорт и восстановление. Восстановление заменяет все таблицы одной транзакцией, проверяет формат и связи и предварительно сохраняет `data/before-restore-*.sqlite3`. Кеши в экспорт не входят. Встроенная схема версионируется таблицей `migrations` (сейчас версия 1); будущие изменения должны добавлять явные миграции.

Не открывайте сервер в публичную сеть: это личное локальное приложение без учётных записей. Интерфейс не использует внешние скрипты; Origin и Host ограничены локальным адресом. Данные не отправляются внешним моделям. В Explorer отправляется только выбранный FEN.

## Проверки

Из каталога проекта:

```sh
.venv/bin/python -m pytest -q
```

На Windows:

```bat
.venv\Scripts\python -m pytest -q
```

Проверяются реальные UCI-расчёты, законность подготовленных решений, правила шахмат, транспозиции, отказ при отсутствии движка, повреждённые/незавершённые PGN, импорт/дедупликация, анализ партии и упражнения, отмена без частичных записей, расписание, экспорт/откат восстановления, адаптеры API и кеш/429/offline. Stockfish нужен для движковых тестов; они не подменяются моками.

Браузерная проверка дополнительно требует Playwright и Chromium. Остановите текущий сервер, чтобы освободить порт 8765:

```sh
.venv/bin/python -m pip install -r requirements-ui.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/ui_smoke.py
```

Можно задать `ACADEMY_BROWSER` — путь к установленному Chromium. Проверка сама поднимает сервер с временной БД, проходит доску и учебные сценарии, разбирает реальную PGN движком, проверяет мобильную ширину и перезапускает сервер для проверки сохранности данных. Пользовательская база не меняется. Скриншот записывается в игнорируемый `ui-artifacts/`.

## Структура и лицензии

- `academy/db.py` — схема, идентичность позиций, резервные копии.
- `academy/engine.py` — UCI, очередь, кеш и классификация.
- `academy/curriculum.py`, `coach.py`, `learning.py` — учебные материалы, объяснения, повторения и анализ партий.
- `academy/sources.py` — PGN, публичные API и сетевой кеш.
- `academy/main.py` — локальный HTTP API; `academy/static/` — интерфейс без сборщика.
- `setup_local.py`, `run.py`, `start.bat` — проверяемая установка и запуск.
