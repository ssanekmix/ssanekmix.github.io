## Дополнение: запуск без установки

По запросу пользователя добавлена настоящая браузерная версия для GitHub Pages в index.html и web/: локальные chess.js / Stockfish WASM, IndexedDB, Service Worker и PWA. Она работает без Python API. Целевой адрес https://ssanekmix.github.io/chess-academy/. Личная база не попадает в Git; браузерные резервные копии имеют отдельный формат. Тест tests/web_smoke.py обслуживает только статические файлы и проверяет реальную работу движка, данных и offline. Статус публикации проверяйте по GitHub Pages; наличие кода не доказывает публикацию.

## Реализовано и проверено

- Python 3.12 / FastAPI / SQLite / python-chess / локальный UCI Stockfish 17.1; браузер без сборщика и внешних ресурсов.
- Windows-скрипт и кроссплатформенный launcher с venv, закреплёнными зависимостями, официальными архивами и SHA-256. Linux x86-64 AVX2 проверен; реальная Windows остаётся отдельным обязательным прогоном.
- Произвольный FEN, все легальные ходы, история, рокировка, en passant, выбор превращения, терминальные позиции и повторения с историей.
- 16 русских курсов / 48 веток, 3 865 дополнительных ECO-названий; собственные PGN-ветки и транспозиции; обучение за оба цвета и свободное исследование.
- MultiPV, глубина/время, остановка и ограниченная очередь, кеш, классификация по WDL + cp + мату. Результаты ограниченного расчёта явно предварительные.
- Правдивые объяснения особенностей хода и реальной PV, авторские заметки для первых ходов, стрелки, атаки, сохранение позиций и заметок. Продвинутые планы не выдумываются.
- Режимы обучения, угадывания, памяти, случайного соперника и работы с ошибками своих партий. Свободный текст — самооценка, не автоматическая проверка.
- Законченные PGN: строгий контроль токенов/результатов, легальности, ошибок и дублей; Chess.com archives/month API; проверены живые архивы Sanekmix и реальная завершённая партия: 39 полуходов, два созданных упражнения (во временной БД).
- Полный анализ партии, воспроизведение, график, лучшие альтернативы, критические решения и упражнения из ошибок пользователя.
- 23 коротких урока, из них 10 с конкретными решениями, проверяемыми Stockfish; произвольное личное упражнение через движок.
- Интервальные повторения, адаптация с воротами по успешной практике, базовые показатели прогресса, дебютные результаты, доступные рейтинги и часы.
- Экспорт/транзакционное восстановление, резервная SQLite-копия перед заменой, версия схемы 1.
- 47 pytest-проверок и отдельный Chromium-сценарий с реальным движком, мобильной шириной и перезапуском процесса. Контрактные фикстуры API явно отделены от живых сетевых проверок.

## Следующие приоритеты

1. **Живой Opening Explorer.** Оба хоста `explorer.lichess.org` и `.ovh` после разрешения доменов отвечают 401. Формат реализован по официальной спецификации, кеш/429/offline и UI проверены. Причина отказа публичного сервиса не установлена; не добавляйте выдуманные данные или фиктивный токен. После изменения доступа повторите один запрос. До успешного живого ответа не считайте этот сценарий завершённым.
2. **Windows acceptance.** На настоящей Windows x86-64 выполните start.bat в чистом каталоге, проверьте первый запуск, автооткрытие браузера, повторный offline-запуск, пути с пробелами и сохранение БД. Архив для Windows получен по HTTPS и его SHA закреплён, но это не заменяет исполнения exe на Windows.
3. **Дальнейшее методическое наполнение.** Уже добавлены 10 деревьев и восемь фактических разделов объяснения. Для каждого курса разметить идеи/ответы/типичные ошибки/редкие продолжения на каждой позиции, со ссылкой на проверенный анализ. Сейчас глубокие объяснения вне авторских заметок честно ограничены. Не называйте любой неосновной ход ошибкой. Добавить отдельные проверенные метки сложного допустимого хода и практической ловушки.
4. **Продвинутые учебные модули.** Задачи Lichess теперь подключены без внутреннего дневного лимита. Расширить упражнения по всем заявленным мотивам, точные позиции Люцены/Филидора и многоуровневые уроки до продвинутой подготовки. Сейчас есть реальная база и короткие исследовательские материалы; это не многолетний полный курс. При импорте открытых задач хранить лицензию, источник и факт движковой проверки, без многогигабайтной начальной загрузки.
5. **Диагностика ошибок.** Усовершенствовать разметку «зевнул фигуру / вилка / пропущенный мат / рокировка / реализация» на основе проверяемых изменений и последовательностей. Сейчас категории упражнений крупные (дебют, тактика, эндшпиль, матовая атака), а геометрические мотивы ограничены шахом, связкой и возможной вилкой. Не выдавать простую геометрию за тактическое доказательство.
6. **Планы и память.** Добавить проверенные многошаговые планы и автоматическую постановку проблемных дебютных позиций в повторения. Сейчас автоматическое расписание получают ошибки партий, встроенные задачи и вручную созданные упражнения; результаты ходов дебютов сохранены отдельно.
7. **Аналитика на большой выборке.** Разделить частоту зевков именно пользователя, устойчивость расчёта, типы окончаний и потери времени по сериям партий. Сейчас доступны исходные часы и остатки; вывод о причине цейтнота намеренно не делается. Уточнить названия ECO при транспозициях без ложной точности.
8. **Условия Chess.com.** Живые публичные JSON-эндпоинты работают; актуальную страницу условий нужно отдельно перепроверить перед распространением интеграции. Никаких live-партий и автоматизации ходов.

## Как продолжать

Рабочая директория — каталог chess-academy в существующем checkout. Отдельный worktree не нужен: облачная задача уже изолирована. Сначала прочитайте README.md и THIRD_PARTY.md, затем выполните `.venv/bin/python -m pytest -q`. Для UI нужен свободный порт 8765: `python tests/ui_smoke.py` при установленном Playwright/Chromium. Тест использует временную БД, пользовательские файлы не очищайте. При изменении схемы добавляйте миграцию; не удаляйте data ради прохождения тестов.
